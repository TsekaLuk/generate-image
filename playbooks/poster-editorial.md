# Playbook: Posters, Covers & Editorial Graphic Design

> **Core rule:** Great graphic design comes from **grid discipline, focal contrast, negative space, and typographic hierarchy** — not cramming every element into the center.

## 1. Layout Archetypes (Pick ONE Explicitly)
- **Swiss International Grid:** Strict mathematical alignment, asymmetrical hierarchy, bold sans-serif headline block, crisp dividing hairlines, 35–45% intentional negative space, single stark accent color (e.g. Swiss red / cobalt / acid yellow).
- **Editorial Hero Cover (Article / Video Thumbnail / Book):** One unmistakable visual metaphor occupying 55–65% of frame (positioned off-center or lower-third), paired with a dedicated clean **30% Title Safe Zone** (calm sky, solid matte field, or soft gradient).
- **Typographic Monumental Poster:** Oversized architectural display typography integrated with a minimal focal object (subject partially overlapping or framed by bold quoted letters).
- **Risograph / Print Zine:** Tactile 2–3 spot-ink overprint aesthetic, visible halftone grain, matte uncoated paper texture, bold high-contrast silhouette.

## 2. Typography Safety Contract
- **Short exact strings only:** Wrap every headline/subhead in quotes (`"FUTURESTACK '26"`, `"设计系统指南"`).
- **Placement + Case + Weight:** Explicitly specify where each string sits (`top-left aligned bold grotesque uppercase`, `bottom-right small tracked monospace caption`).
- **Anti-hallucination lock:** Always add *"render ONLY the exact quoted text strings and no other text anywhere on the poster"*.
- **When copy is long (> 15 chars):** Do NOT bake paragraphs into pixels. Explicitly reserve an empty **title/copy safe zone** (`clean uncluttered upper 30% matte canvas reserved for post-overlay typography, zero text rendered in image`).

## 3. Six-Layer Prompt Blueprint
1. **Deliverable & Purpose:** Event poster / editorial cover / launch key visual / social carousel slide.
2. **Grid & Visual Hierarchy:** Exact composition system (`Swiss grid`, `asymmetrical lower-right hero + top-left title safe zone`, `centered iconic emblem`).
3. **Focal Metaphor / Subject:** One strong conceptual object or scene — never 5 competing subjects.
4. **Typography Spec:** Exact quoted headline + optional subhead + placement + font character (or explicit *"no text, clean safe zone"*).
5. **Medium, Craft & 60-30-10 Palette:** Print/editorial craft cues (matte paper stock, risograph grain, flat silkscreen, editorial photography) + explicit color ratios.
6. **Targeted Negatives:** *"No generic stock gradients, no cluttered corners, no extra random letters, no watermarks, no low-contrast text."*

## 4. Board-First Concepting (6 Directions in 1 Call)
For vague poster briefs ("帮我做张活动海报，风格你定"):
1. Generate a **`2x3` Exploration Board** (`grid: {rows: 2, cols: 3}`) testing 6 distinct visual schools in ONE call: A=Swiss Grid, B=Risograph Print, C=3D Minimalist Object, D=Bold Editorial Illustration, E=High-Contrast B&W Photo + Accent, F=Kinetic Typography.
2. Visually inspect the board → pick the strongest direction (e.g. `A`) → slice `@board:A` → expand into full-res vertical poster (`4:5` / `9:16`) + horizontal banner (`16:9`) + square social cut (`1:1`) via DAG!
